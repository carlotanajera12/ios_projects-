# Project 2 - Wordle Settings

Submitted by: **Carlota Najera**

**Wordle Settings** is an iOS app that expands on the original Wordle game by allowing users to customize gameplay. Users can change the word length, number of guesses, select different word themes, and enable an “alien wordle” mode where the goal word changes after each guess.

Time spent: **5–7 hours** spent in total

## Required Features

The following **required** functionality is completed:

- [x] User can change the number of letters per row (the length of the goal word)
- [x] User can change the numbers of rows on the board (how many guesses allowed)
- [x] User can select a new themed set to pull the goal word from
- [x] User can select "alien wordle", causing the goal word to change after each guess
