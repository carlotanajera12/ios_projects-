# Project 4 - Trivia App

Submitted by: **Carlota Najera**

**Trivia App** is an iOS app that allows users to answer trivia questions fetched from an online API. Users can go through a series of questions, select answers, and view their final score at the end.

Time spent: **5–7 hours** spent in total

## Required Features

The following **required** functionality is completed:

- [x] User can view and answer at least 5 trivia questions
- [x] App retrieves question data from the Open Trivia Database API
- [x] Fetch a different set of questions if the user resets the game
- [x] Users can see score after submitting all questions
- [x] True or False questions only have two options
